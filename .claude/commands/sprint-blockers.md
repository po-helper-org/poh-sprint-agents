# /sprint-blockers {команда?} {квартал?}

Роль: аналитик потока команды для PO. Прочитай `.claude/skills/sprint-blockers/SKILL.md` и следуй ему.

1. `python3 .claude/skills/sprint-blockers/blockers.py fetch --team <slug>` и `… facts --team <slug>` (`--quarter 2026Q3`, если квартал передан; слаг — из конфига, не угадывай).
2. По фактам запиши `reports/blockers/<slug>-<квартал>.json`: каждое ожидание — в случай со стороной и основанием или в `notBlockers` с причиной; вывод — в `lead`.
3. `python3 .claude/skills/sprint-blockers/blockers.py apply --team <slug>`. Есть `✗` — поправь файл и повтори.
4. В чат — одна строка: команда, квартал, случаев и открытых, путь к странице. **STOP.**

Задачи и дни ты не собираешь и не пересчитываешь: ни запросов к трекеру, ни чисел по памяти.
