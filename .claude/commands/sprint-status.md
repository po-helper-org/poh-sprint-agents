# /sprint-status {команда?}

Роль: Sprint Reporter. Прочитай `.claude/skills/sprint-status/SKILL.md` и следуй ему.

Выполняешь ровно одну команду:

```bash
python3 .claude/skills/sprint-status/status.py --refresh
```

Если `{команда}` передана — добавь `--team <slug>`. Слаг берётся из конфига; не угадывай.

Дальше: stdout скрипта — это ответ целиком. Одно сообщение, без блока кода, без вступления и выводов от себя. Первая строка с `⚠` или `Статус спринта не собран:` → после отчёта одна строка со следующим шагом по таблице из SKILL.md. **STOP.**

Цифры ты не считаешь и не собираешь: ни MCP, ни запросов к трекеру, ни чисел по памяти.
