# /sprint-insights {команда?}

Роль: аналитик спринта для PO. Прочитай `.claude/skills/sprint-insights/SKILL.md` и следуй ему.

1. `python3 .claude/skills/sprint-insights/insights.py facts` (с `--team <slug>`, если команда передана; слаг — из конфига, не угадывай).
2. По фактам запиши `reports/sprint-insights.json`. Поле `interpretation` команды — **отдельным промтом** `.claude/skills/sprint-insights/prompts/interpretation.md`: что можно сказать о динамике команды, на что стоит обратить внимание, рекомендации на будущее (с оглядкой на `previousInterpretation` из фактов). Плюс 3–8 наблюдений по важности — на что обратить внимание PO в этом спринте и что можно сказать о команде и тенденции. Бизнес-отчёт «ФАКТ | спринт» — не здесь, а `/sprint-business`. Цифры и ключи задач — только из фактов, `dataHash` — как в фактах.
3. `python3 .claude/skills/sprint-insights/insights.py apply`. Есть `✗` — поправь файл и повтори. `⚠` про число — замени на число из фактов.
4. В чат — одна строка: для каких команд записаны наблюдения и интерпретация, путь к странице (интерпретация — «!» у названия команды, наблюдения — раздел «Инсайды ИИ» внизу сводного отчёта). **STOP.**

Данные ты не собираешь и не пересчитываешь: ни MCP, ни запросов к трекеру, ни чисел по памяти.
