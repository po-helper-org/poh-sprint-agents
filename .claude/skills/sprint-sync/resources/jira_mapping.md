# Маппинг JIRA → отчёт спринта

Что и откуда берёт `scripts/sprint_sync.py`. Поля, которых нет в ответе, не достраиваются.

## Источник задач

| Режим | Запрос | Когда |
|---|---|---|
| доска (дефолт) | `GET /rest/agile/1.0/board/{board_id}/sprint?state=active` → `GET /rest/agile/1.0/sprint/{id}/issue` | в профиле задан `jira.board_id` |
| JQL | `GET /rest/api/2/search?jql=…` | задан `jira.jql` или флаг `--jql`; плейсхолдер `{sprint}` подставляется из `--sprint` |

Активных спринтов несколько и `--sprint` не задан → скрипт останавливается и печатает список имён. Пагинация — по 100 задач до `total`/`isLast`.

## Поля задачи

| Поле ответа | Куда идёт | Правило |
|---|---|---|
| `key`, `fields.summary` | колонка «История» | ссылка `{base_url}/browse/{key}` в HTML |
| `fields.status.statusCategory.key` | категория: `done` / `indeterminate` / `new` | опора на категорию, а не на имя статуса — имена кастомизируются в каждом инстансе |
| `fields.status.name` | текст статуса в отчёте | показывается как есть, не переводится |
| `fields.assignee.displayName` | колонка «Команда» | пусто → `[УТОЧНИТЬ исполнителя]`, роль по типу задачи не угадывается |
| `fields.issuetype.subtask` | история или подзадача | `true` → подзадача, крепится к `fields.parent.key` |
| `fields.subtasks[]` | подзадачи-заглушки | добираются, если полный объект подзадачи не пришёл в выборке спринта; у заглушки нет исполнителя |
| `jira.story_points_field` (дефолт `customfield_10016`) | SP | не число → прочерк и строка в «Требует внимания» |
| `fields.updated` | «без движения N дн.» | отсчёт от `meta.fetched_at` |
| `fields.duedate` | «просрочены» | только для незакрытых |
| `fields.parent.key` | эпик истории | хранится, в краткий отчёт не выводится |

`done_statuses` из профиля — запасной путь для инстансов без `statusCategory`: имя статуса из списка → категория `done`.

## Аутентификация

`JIRA_TOKEN` → `Authorization: Bearer` (Server/DC). `JIRA_EMAIL` + `JIRA_API_TOKEN` → `Basic` (Cloud). Корпоративный CA — `JIRA_CA_BUNDLE`. Проверка TLS не отключается ни при каких ошибках сертификата.

## Коды возврата

| Код | Значение | Что делать |
|---|---|---|
| 0 | отчёт записан | вывести таблицу в чат |
| 2 | конфигурация или доступ (нет `base_url`, нет токена, 401/403/404, спринт не выбран) | назвать недостающее, остановиться |
| 3 | JIRA недоступна после 4 попыток (2/4/8 с) | показать сообщение, не подменять данные кэшем |

## Evidence

`--save-raw payload.json` кладёт сырой ответ рядом с отчётом. Тот же файл через `--from-json` рендерит отчёт офлайн — так воспроизводится спорная цифра без повторного обращения к трекеру.
