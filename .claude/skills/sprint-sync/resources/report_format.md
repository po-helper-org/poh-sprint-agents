# Формат отчёта sprint-sync

Два представления одних и тех же данных: страница для чтения и таблица для чата.

## Краткий отчёт (текст)

Шапка — три строки: источник и время синка, период спринта, прогресс (`задачи X/Y готово · в работе N · не начато M · SP A/B · день D из T`). Дальше таблица:

```
| Команда | История | Что сделано | Что осталось |
```

| Колонка | Содержимое |
|---|---|
| Команда | `displayName` исполнителя; повторно в соседних строках не дублируется; без исполнителя → `[УТОЧНИТЬ исполнителя]` последней группой |
| История | `{KEY} {краткий заголовок} · {SP} SP`; заголовок режется до 52 символов |
| Что сделано | `история закрыта · {статус}` и/или `подзадачи k/n: {ключи}`; ничего не закрыто → прочерк |
| Что осталось | `в работе: …` и `не начато: …` по подзадачам; подзадач нет → `вся история · статус {статус}`; всё закрыто → прочерк |

Списки подзадач — до трёх ключей, дальше `+N`. Разделитель внутри ячейки — ` · `. Символ `|` в заголовке задачи заменяется на `/`, переносы строк схлопываются.

Ниже таблицы: итог по каждому исполнителю (закрыто историй, SP закрыто из назначенных) и блок «Требует внимания» — только сработавшие детекторы, каждый одной строкой.

## HTML-страница

Порядок блоков: шапка (спринт, период, синк, цель спринта из JIRA, полоса прогресса, переключатель «скрыть закрытые истории») → плашки счётчиков → «Требует внимания» → карточки исполнителей с подзадачами → та же таблица из четырёх колонок → подвал с отметкой «только чтение».

Страница самодостаточна: разметка и стили в одном файле, без внешних шрифтов, скриптов и запросов. Тема — светлая и тёмная по `prefers-color-scheme`. Ширина от 360 px: плашки и карточки перестраиваются в колонку, таблица получает горизонтальную прокрутку.

Цветовая семантика статусов: закрыто — зелёный, в работе — янтарный, не начато — серый, риск — красный. Цвет дублируется текстом статуса, отчёт читается и без цвета.

## Стиль

Отчёт машинный: статусные цвета и прочерки допустимы, декоративные эмодзи — нет. Проза трактовки в чате — по `.claude/skills/sprint-planner/resources/writing_style.md`: прямые сказуемые, без «позволяет», «обеспечивает», без анонсов.

Оценок «команда отстаёт» без опоры на цифру отчёта не бывает. Правильно: «GDSLV-1510 (6 SP, Must по плану) не начата на 6-й день из 13 — Sprint Goal по кино под риском».
