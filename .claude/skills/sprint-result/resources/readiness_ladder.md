# Лестница готовности — как выводится процент

Процент в колонке «Результат» **не называется на глаз, а выводится**: находим
верхнюю ступень, которую строка реально прошла к концу спринта, и берём её
число. Ступень пишется рядом с числом — по ней видно, откуда оно (гейт 3).

Источник лестницы — референсная колода (`docs/reference/sprint-report-reference.md`
§4.1), а не изобретение навыка.

## Базовая лестница (поставка фичи)

| Ступень | % | Что доказано |
|---|---|---|
| Документация и аналитика согласованы | 20 | решение принято, разработка может стартовать |
| Разработка завершена | 50 | код написан, на стенде разработки |
| Ревью пройдено | 80 | код принят, ждёт тестов |
| Тесты и отладка закончены | 95 | ошибок нет, ждёт окна выкатки |
| В Production | 100 | пользователь видит результат |

## Лестница исследования (`[SPIKE]`, `[SA]`-строки)

| Ступень | % |
|---|---|
| Материалы изучены, границы понятны | 10 |
| Аналитика завершена, решение описано | 50 |
| Решение согласовано с архитектором / смежниками | 70 |
| Артефакт передан в разработку | 100 |

## Лестница переключения нагрузки

Доля переключённого трафика напрямую: `30 / 50 / 70 / 90 / 100%`. Ступень —
это доля, а не этап разработки.

## Правила вывода

1. **Ступень — доказанное состояние, не ощущение прогресса.** «Почти
   доделали» ступенью не является.
2. **Откат считается по достигнутой ступени, а не по факту отката.** Выкатили
   и откатили → ступень «ревью пройдено, откат при выкатке», 80%. Ставить 99%
   потому, что «оставалось чуть-чуть», нельзя: в проде этого нет.
3. **Ступень не определяется → `[УТОЧНИТЬ]`**, а не среднее число. Гейт 3
   проверяет наличие названной ступени, не правдоподобность процента.
4. **Своя лестница у строки — можно**, если она названа явно в комментарии
   («переключение по долям трафика»). Тогда ступень берётся из неё.
5. **`ACTIVITY` и `заблокировано` — вне шкалы.** Ступень при них называет
   достигнутое состояние, процент не ставится.
6. **PO подтверждает или правит.** Вывод предлагает агент, решение за PO
   (решение О2). Правка PO становится источником и записывается как есть.

## Что лестница не делает

Не превращается в среднее по спринту. Светофор считает **строки по статусам**
(решение Д1), а не взвешенный процент: «спринт закрыт на 80%» при двух
незакрытых Must — цифра, вводящая в заблуждение.
