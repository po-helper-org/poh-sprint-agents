# Форма данных для шаблона

`resources/report_template.html` рендерит таблицу из одного JS-массива `EPICS`. Единица отчёта — **эпик**, не история (PO трекает прогресс на уровне эпика). Заполняй массив целиком (не трогай остальной JS/CSS шаблона):

```js
{
  rowId: "GDSLV-1737",              // уникален на СТРОКУ — обычно = epicKey; "no-epic" для псевдо-эпика
  epicKey: "GDSLV-1737",             // null → строка рендерится как псевдо-эпик "Без эпика"
  epicTitle: "AI Harness (Bartello)",
  stories: [
    {
      key: "GDSLV-1919",
      title: "Harness DevAgent",     // summary истории
      status: "Бэклог",              // status.name истории — текст на бейдже
      category: "К выполнению",      // statusCategory.name истории — для цвета бейджа
      subtasks: [
        { key: "GDSLV-1881", summary: "[FAQ] Direct: новый таб FAQ на страницах", status: "Ревью", category: "В работе" }
      ]
    }
  ]
}
```

## Псевдо-эпик «Без эпика»
Истории без эпик-линка не выбрасывай — собери их в один элемент массива с `epicKey: null`, `epicTitle: "Без эпика"` (или без `epicTitle` — шаблон сам подставит), `rowId: "no-epic"`.

## Группировка — только визуальная
Никакой агрегированной метрики (% выполнено, счётчик "3 из 5") в строке эпика не считать и не выводить — PO попросил именно визуальную группировку, не сводный статус. Агрегация — не задача этого навыка.

## Сайдбар «Статус» (одна кнопка на эпик)
Один сайдбар, две секции сверху вниз:
1. **Прогресс** — заметка привязана к эпику (`rowId` эпика). `localStorage`-ключ: `actual-sprint:{REPORT_ID}:note:{rowId}`.
2. **Истории** — список историй эпика: `key — title` + статус-бейдж истории. Если у истории есть подзадачи — стрелка-тоггл разворачивает их список под историей (тот же принцип статус-бейджа, но для `subtasks`). Нет подзадач у истории → стрелка скрыта (`disabled`), просто нет разворота.

## Категории статусов → бейдж
| statusCategory.name (JIRA) | css-класс в шаблоне |
|---|---|
| Выполнено | done |
| В работе  | progress |
| всё остальное (К выполнению и т.п.) | backlog |

Правило применяется и к историям, и к их подзадачам.
