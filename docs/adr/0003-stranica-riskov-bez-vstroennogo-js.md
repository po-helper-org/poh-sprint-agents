# Страница рисков — готовый HTML без встроенного JS

Колода «ФАКТ | спринт» — шаблон с данными и встроенным JS; её nginx отдаёт под отдельной CSP (`script-src 'unsafe-inline'`) только по путям `/business/api/(deck|fresh)`. Страницу рисков `quarter.py render` собирает целиком на сервере: таблица, раскрытие строк через `<details>`, печать без скриптов. Поэтому она работает под общей CSP `/business/api/` (`script-src 'self'`) без правки nginx, которая требует sudo владельца, и печатается в PDF как есть. Кнопки (✅ эскалации, «Скопировать для CPO», «Обновить») — внешним файлом виджета `/business/risks.js`, которому CSP `'self'` разрешает.

## Consequences

- Логика отчёта (прогноз, статусы, эскалации) — в Python и проверяется юнит-тестами, а не в браузере.
- Страница без виджета (файл на диске) читается полностью, только кнопки не работают.
