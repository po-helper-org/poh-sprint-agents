В следующий спринтПеренос в 2026Q3-S9 и следующие шаги

Кандидаты в carryover — четыре строки, все с известной причиной:

  • Переключение B2C-трафика (80%) — правка конвертера схем и повторная выкатка.
  • Схема хранения для второго поставщика (50%) — решение по идентификаторам площадок.
  • Уведомления по новому типу контента (заблокировано) — вебхук смежной системы.
  • Задержка синхронизации каталога — закрыть без временного решения.

Следующие шаги: (1) вынести перенос в /sm-sync 2026Q3-S9, (2) эскалация по вебхуку на синке команд, (3) подтвердить у PO ступень для строки схемы хранения.
