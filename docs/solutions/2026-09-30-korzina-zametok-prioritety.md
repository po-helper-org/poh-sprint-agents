# Корзина заметок, приоритеты в отчёте и эталон разбора квартала

## Ситуация

Заметки в отчёте жили в textarea внутри панели эпика и выгружались отдельным файлом — на телефоне ими было не пользоваться, к сущности их нельзя привязать. Приоритетов у задач в отчёте не было вовсе. Для будущего навыка ретро квартала не было эталона «как выглядит хороший разбор».

## Причина

Заметки проектировались как поле ввода, а не список привязанных к сущностям записей; приоритет не забирался сборщиком. Эталон разбора квартала существовал только как внутренний артефакт с реальными именами.

## Решение

- **Корзина «Комментарии (N)»** справа вверху: заметка — строка текста, правый клик по эпику/истории/подзадаче/событию ленты создаёт заметку к ней; правка прямо в строке; ключ не из отчёта сохраняется как «Вне отчёта». Старые заметки из браузера и файла переносятся в корзину один раз.
- **«Скопировать промт для ИИ»**: строки вида `N. [тип ключ «название» · эпик · приоритет · статус · исполнитель] текст` — модель сразу видит, о какой сущности речь; снимок сущности фиксируется на момент записи.
- **Приоритеты**: базовый сборщик (1.1.0) забирает `priority` у эпиков, историй и подзадач; в схеме поля необязательные — свои сборщики не ломаются. На странице значок `⇈ ↑ = ↓ ⇊`, точное название — в подсказке.
- **Эталон разбора квартала**: `docs/quarter-retro/ideal_quarter_fact.html` — обезличенный итог квартала (люди → «Участник Б…Э», внутренние идентификаторы убраны); `TARGET.md` описывает, куда должен прийти будущий навык ретро; тест ловит возврат реальных ФИО.

После мержа базовый сборщик изменился — в strict-режиме командам нужно заново пройти `/collector-validate`.

## Как проверить

- `python3 -m unittest discover tests` — 162 теста; e2e по корзине и странице.
- Правый клик по истории → заметка с ключом в корзине; «Скопировать промт для ИИ» → строка с приоритетом и статусом.
- Тест эталона: реальные ФИО в файле → красный.

## Уроки

- Заметка, привязанная к сущности (ключ + снимок на момент записи), переживает пересборку страницы; свободный текст в textarea — нет.
- Необязательные поля в схеме — способ добавлять данные, не ломая чужие сборщики.
- Эталон-пример «как хорошо» с тестом на обезличенность полезнее описания словами; позже аудиторская проверка нашла в нём остатки названий (см. кейс об обезличивании эталона).
