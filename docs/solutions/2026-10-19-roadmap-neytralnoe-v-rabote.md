# Роадмап без агента: фазы не угадываются

## Ситуация

Владелец спросил, откуда в роадмапе «разработка/приёмка». Без бизнес-блока агента фаза определялась эвристикой по префиксам задач ([SA]→аналитика, [BE]→бек, [QA]→qa, иначе «разработка»); у двух команд префиксов почти не было — почти все ячейки показывали «разработка», и каркас выглядел как осмысленный план.

## Причина

Эвристика по заголовкам задач — выдумка там, где данных нет: полоса фаз без знания плана создаёт ложное впечатление точности.

## Решение

- Без блока агента в ячейках роадмапа только нейтральное **«в работе»** (полоса до срока или прогноза) и «приёмка» в последней неделе перед сроком.
- Фазы по неделям (аналитика → бек → qa → приёмка) — только из `roadmap` агента; «в работе» добавлена в словарь фаз (схема, SKILL.md).
- Под «Рисками и проблемами» подпись «из данных: блокеры и сроки, агент дополнит» убрана.

## Как проверить

- e2e `business_deck.mjs`: без агента в ячейках только «в работе» и «приёмка»; на main первая проверка падает (там «разработка»/«бек»).
- `unittest discover` — 377 OK.

## Уроки

- Отчёт без данных для детали лучше показывает нейтральное значение, чем эвристику: угаданная фаза читается как план.
- Вопрос владельца «откуда это» — сигнал, что элемент интерфейса не объясняет свой источник; либо объясняй, либо не показывай.
