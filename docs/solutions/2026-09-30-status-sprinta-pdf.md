# Статус спринта одним PDF — детерминированный, для рассылки по расписанию

## Ситуация

PO-агент на вопрос «как спринт» отвечал понятно, но каждый раз по-разному: одного и того же вопроса не было и двух одинаковых ответов. Рассылать такой статус по расписанию было нельзя.

## Причина

Статус считал и формулировал один агент в свободной форме — нет источника истины ни для чисел, ни для вида.

## Решение

Новый навык `/sprint-status`:

- `model.py` считает показатели, `page.py` строит лист 16:9 в визуальном языке утренних слайдов, `pdf.py` печатает через headless Chrome/Chromium без Python-зависимостей.
- Лист команды: шесть KPI (готово, темп против идеальной прямой, за сутки, блокеры, без движения, зона риска), burndown, статусы, список «Внимание», эпики; если команд несколько, первым идёт сводный лист.
- **Числа из того же снимка, что и страница**: runner (`run` и `merge`) пишет `reports/sprint-report.data.json` рядом с HTML, поэтому цифры в PDF и на странице совпадают; модель ничего не считает сама.
- Вывод в чат: stdout — одна строка подписи и `MEDIA:<pdf>`; обёртка для cron в режиме без агента прикладывает файл сама.
- Отказ сбора не глушит рассылку: трекер недоступен → PDF по последнему снимку с плашкой и причиной.

При отладке на replay нашли и исправили: зона риска считалась по трём спринтам, а не по текущему; просроченный незакрытый спринт показывался как «последний день»; идеальная прямая лежала на нуле при задачах, внесённых через минуты после старта; в демо-данных burndown расходился со статусами.

## Как проверить

- `python3 -m unittest discover tests` — 162 теста на Python 3.11 и 3.10.
- Cron-прогон без VPN: приходит PDF по последнему снимку с плашкой причины, а не тишина.

## Уроки

- Повторяемый ответ «как спринт» = фиксированная модель показателей + общий снимок данных; агент тогда только доставляет.
- Рассылка по расписанию должна переживать недоступность источника: последний валидный снимок с пометкой лучше молчания.
- Прогон на replay до выпуска нашел четыре счётные ошибки — модели показателей тоже нужны тесты.
