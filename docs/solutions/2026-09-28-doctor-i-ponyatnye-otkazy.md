# Первая отладка на живом трекере — doctor и понятные отказы

## Ситуация

Фикстуры проверяли логику, но не окружение. Первый запуск сборщика на живом инстансе трекера спотыкался о вещи, которых нет в тестах: самоподписанный TLS-сертификат, 401, неразрешимый хост (502 из туннеля). Симптомы были одинаковые — сбор не идёт, причина непонятна.

## Причина

Сообщения об ошибках соединения не различали причину: совет «проверьте VPN и адрес» показывался и при проблеме с сертификатом. Имя доски искалось постраничным обходом всех досок инстанса — десяток запросов и прав на чтение всего списка.

По дороге нашли ещё одну: токен с кириллицей ронял сборщик трейсбеком `UnicodeEncodeError` при сборке заголовка.

## Решение

Прогнали отказы окружения вживую (локальный HTTPS с самоподписанным сертификатом, сервер с 401, неразрешимый хост) и закрыли каждое своим сообщением:

- проверка сертификата не прошла → «сертификат не проверился … укажите jira.ca_bundle», а не совет про VPN;
- 401 → «проверьте токен»;
- имя доски → один `GET /rest/agile/1.0/board/{id}` вместо обхода списка; 404 → «доски #N не существует или она не видна этому токену»;
- не-ASCII токен → ошибка конфигурации «скопируйте токен заново» без трейсбека;
- новая команда `doctor` — стенд без похода в сеть: файлы, конфиг, env, CA, lock по командам; репетиция первого запуска из чистой установки до зелёного `run`.

Отладочный runbook — `docs/actual-sprint-debug.md`: порядок первого запуска и таблица «сообщение → причина → действие».

## Как проверить

- `python3 -m unittest discover tests` — 97 тестов.
- Стенд с самоподписанным TLS без `ca_bundle` → exit 3 с текстом про сертификат; с `ca_bundle` → запрос проходит.
- `doctor` в четырёх состояниях (нет конфига / сборщик не проверен / проверен / готов) и никогда не печатает значение токена.

## Уроки

- Отказы окружения стоит прорабатывать на настоящих сокетах, а не моках: часть сообщений выясняется только вживую.
- Отдельная диагностика `doctor` без сети окупается на каждом новом стенде.
- Паритет с эталоном старого сборщика пересняли после смены ручки доски — сходится побайтово.
