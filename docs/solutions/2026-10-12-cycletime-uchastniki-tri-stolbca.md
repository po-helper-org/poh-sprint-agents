# Cycle time на операционный, участники в три столбца, без «Сроков»

## Ситуация

По просьбе владельца (2026-10-12): cycle time спрятан на отдельном слайде «Сроки», куда не дойти; слайд «Участники» не вмещал переходящие задачи; у команды с одним спринтом на доске столбец прошлого спринта был пуст и непонятен.

## Причина

Разбор сроков делался отдельным слайдом с собственным входом («Заблокировано» → клик), и без самого слайда входы терялись. Колонка «Задачи из прошлого спринта» требовала данных предпоследнего спринта, которых на маленькой доске нет.

## Решение

- **Cycle time — внизу операционного слайда во всю ширину**: полосы спринтов, точки историй и подзадач, скользящие средние по 5 последним задачам с коридором ±σ. Клик открывает прежний разбор: «Все / Истории / Подзадачи», показатели, диаграмма управления, таблица по спринтам.
- **Слайда «Сроки» больше нет**; время в статусах и разбор блокировок убраны вместе с ним. Сборщик `timeInStatus` продолжает отдавать данные.
- **«Участники» — отдельный слайд в три столбца**: «Задачи из прошлого спринта» (история текущего, которая была и в предыдущем — правка сборщика не нужна), «Текущий спринт», «Вне спринта» (`output.offboard`). Ширина столбца — по самому длинному ряду, минимум 16%; если на доске один спринт, столбец пустой.
- Демо-данные: в прошлом спринте появились переходящие истории; покрытие экранов в валидаторе 27 → 26.

## Как проверить

- `python3 -m unittest discover -s tests` — зелёный (кроме двух известных ошибок паритета на Python 3.10).
- e2e: `business_deck`, `comments_persist`, `report_mobile` — все ✓.
- Живые данные трёх команд: операционный слайд без прокрутки, участники в три столбца.

## Уроки

- Точка входа в разбор должна жить на видимом экране: слайд, до которого не дойти, равен отсутствующему функционалу.
- Переиспользование данных («история была в прошлом спринте») дешевле правки сборщика: смотрите, что уже есть в снимке.
- При слиянии живую опубликованную колоду пересобрали на новом шаблоне из её же встроенных данных, с бэкапом — тексты агента и снимок не меняются.
