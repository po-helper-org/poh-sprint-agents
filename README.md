# poh-sprint-agents

Автономный скрам-мастер-агент. Навык `sprint-planner` (slice 1): спринт → согласованный vault-ПЛАН + операционный контракт + гейт консенсуса. Навык `actual-sprint`: факт текущего спринта → самодостаточная HTML-страница отчёта по команде.

## Установка
`bash install.sh [target-проект]` — копирует навыки и команды (non-destructive), кладёт `domain-profile.md` из шаблона.

## Команды

### Планирование (STOP после каждой)
`/sm-sync` → `/sm-goal` → `/sm-decompose` → `/sm-load` → `/sm-deliver` → `/sm-consensus`

### Факт спринта
`/actual-sprint {команда?}` — уточняет команду/спринт → тянет данные из JIRA (доска → активный спринт → истории → эпики → подзадачи) → собирает HTML-отчёт. Единица отчёта — **эпик** (PO трекает прогресс на этом уровне).

Таблица: «Эпик / счётчики статусов / [Статус]». Счётчики — миниатюрный цветной текст вида `2/2/3/0/5/1` (Открыто/Заблокировано/В работе/Тестирование/Ревью/Готово) с расшифровкой по наведению, агрегируется вся иерархия эпика (истории + подзадачи); маппинг реальных статусов JIRA в бакеты выверен регрессией по всем ~330 статусам инстанса (`resources/status_mapping.md`). Кнопка «Статус» открывает два сайдбара сразу: заметка о прогрессе по эпику (автосохранение в localStorage) и список историй с разворотом подзадач. См. `.claude/skills/actual-sprint/SKILL.md`.
