# poh-sprint-agents

Автономный скрам-мастер-агент. Навык `sprint-planner` (slice 1): спринт → согласованный vault-ПЛАН + операционный контракт + гейт консенсуса. Навык `actual-sprint`: факт текущего спринта → самодостаточная HTML-страница отчёта по команде.

## Установка
`bash install.sh [target-проект]` — копирует навыки и команды (non-destructive), кладёт `domain-profile.md` из шаблона.

## Команды

### Планирование (STOP после каждой)
`/sm-sync` → `/sm-goal` → `/sm-decompose` → `/sm-load` → `/sm-deliver` → `/sm-consensus`

### Факт спринта
`/actual-sprint {команда?}` — уточняет команду/спринт → тянет данные из JIRA (доска → активный спринт → истории → эпики → подзадачи) → собирает HTML-отчёт. Единица отчёта — **эпик** (PO трекает прогресс на этом уровне): таблица «Эпик / [Статус историй] [Прогресс]», группировка визуальная, без агрегированного статуса. Кнопка «Статус историй» открывает сайдбар со списком историй эпика (разворот их подзадач по клику), кнопка «Прогресс» — сайдбар с текстовой заметкой на эпик (автосохранение в localStorage браузера). См. `.claude/skills/actual-sprint/SKILL.md`.
