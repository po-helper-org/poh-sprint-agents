# Риски квартала: тексты команды {{TEAM_NAME}}

Когда: по понедельникам до синка PO с CPO (задача cron `quarter-risks-{{TEAM}}`) и когда PO просит «обнови риски квартала», «что поднять CPO», «перепиши эскалацию по KEY».

Ты пишешь только **тексты** для своей команды `{{TEAM}}`: что попросить у CPO и какие риски назвать. Цифры (шанс, прогноз 85%, блокаторы, статусы) считает `quarter.py` — ты их не пересчитываешь и не придумываешь. Подробно про страницу — раздел «Риски квартала» в `{{AGENTS}}/.claude/skills/sprint-business/SKILL.md`, правила — `{{AGENTS}}/docs/quarter-risks.md`.

## Границы

- **Jira — только чтение**: `jira_get_issue`, `jira_search`, `jira_get_issue_dates`, `jira_batch_get_changelogs`. Никаких комментариев, переходов, правок, ссылок, исполнителей.
- Никому не пишешь (ни людям, ни в комнаты) — итог только ответом в этот чат.
- **Оценку PO (`override`) не ставишь и не снимаешь.** Прежнюю `put` сохраняет сам. Новую — только если PO в этом чате сам сказал «поставь красный/зелёный, потому что …»: тогда `put … --with-override`, причина — словами PO.
- ✅ эскалаций ставит PO на странице, не ты.
- Чужие команды не трогаешь: `quarter.py put --team {{TEAM}}` пишет только твою часть файла.

## Шаги

Все команды — из каталога навыка:

```bash
cd {{AGENTS}}/.claude/skills/sprint-business
R={{REPORTS}}
```

1. **Факты:** `python3 quarter.py facts --team {{TEAM}} --reports $R`. Смотри `fetchedAt`: не сегодня — сбор Jira утром не прошёл, работай по ним, но в ответе напиши «данные от <дата>». Код выхода 2 — данных нет: ответь, чего нет, и остановись.
2. **Кого разбираешь:** все строки `teams[0].rows` со `status` `red` или `yellow` и все `candidates`. Строки `green`, `done`, `none` пропускай.
3. **Сверка с Jira (только чтение)** по каждой такой инициативе:
   - есть `blockers` — открой каждый блокатор (`jira_get_issue`, поля `summary,status,assignee,issuelinks,comment`): кого или что ждём (другая команда, партнёр, решение, доступ), с какого числа, что уже просили;
   - `chance` < 0.5 без блокатора — открой эпик: что можно снять из квартала, есть ли зависимости, кто решает про объём или срок.
4. **Черновик** `$R/quarter-risks.drafts/{{TEAM}}.json` (каталог создай, если нет):

   ```json
   {"initiatives": {
     "KEY-1": {
       "escalation": {"ask": "…", "who": "…", "by": "ГГГГ-ММ-ДД", "ifNot": "…", "why": "…"},
       "risks": [{"title": "…", "roam": "Owned", "owner": "…", "due": "ГГГГ-ММ-ДД", "text": "…"}],
       "note": "…"
     }
   }}
   ```

   - `escalation` — только если нужна помощь **выше команды** (снять внешний блокатор, решение по объёму или сроку, люди). Внутренние задачи команды — не эскалация, а риск.
     - `ask` (≤160) — одно действие CPO: «Согласовать с <командой> протокол приёма до …», а не «помочь с задачей»;
     - `who` (≤60) — конкретно у кого: CPO, руководитель смежной команды, партнёр. Не «уточнить» — узнай в Jira;
     - `by` — не раньше сегодня и не позже `okUntil` строки (нет `okUntil` — ближайший понедельник);
     - `ifNot` (≤160) — последствие числами **из facts**: `p85` («с 85% — не раньше ДД.ММ.ГГГГ») или `howMany85` из `open` («к концу квартала успеем N из M открытых задач»);
     - `why` (≤200) — факт из Jira: какой блокатор, с какого числа, кого ждём.
   - `risks` (0–2 на инициативу) — что может случиться: `Owned` (есть владелец, работает), `Mitigated` (снижен), `Accepted` (принят как есть). `Resolved` не пиши — на странице не показывается. `title` ≤80, `text` ≤200, `owner` — человек или роль.
   - `note` (≤200) — по желанию, одна строка для PO.
   - **Не переписывай одобренное:** если в facts у эскалации `source: agent` и `approved: true`, а по Jira ничего не изменилось — перенеси её слово в слово. Переписал хоть букву — ✅ PO слетит.
   - Инициативу, по которой сказать нечего, в черновик не включай — у неё останется текст из данных.
5. **Запись:** `python3 quarter.py put --team {{TEAM}} --author {{PROFILE}} --file $R/quarter-risks.drafts/{{TEAM}}.json --reports $R`. Ошибки (`✗ …`) — поправь черновик и повтори, не больше 3 раз. Файл `quarter-risks.json` руками не правь.
6. **Страница:** `cd {{WIDGET}} && python3 -m business risks --no-fetch`.
7. **Ответ в чат** — 2–4 строки: сколько инициатив под риском, сколько эскалаций написал и какие 1–3 предлагаешь поднять CPO (команда · KR · что прошу), строка «✅ ставит PO на странице» и ссылка {{PAGE_URL}}. Если Jira не ответила или facts упал — так и напиши, текстов не выдумывай.
